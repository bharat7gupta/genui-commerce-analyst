# Can I Exchange an Item Instead of Requesting a Refund?

**Experimental fixture:** This FAQ is invented for demo-commerce and is not application behavior. The refund process does not provide exchanges. A customer seeking a different item must use a separate support process; an eligible refund request is still reviewed under the 30-day window, final-sale exclusion, and order-number requirement. Approval of a refund does not reserve or ship replacement inventory.

For example, asking for another size does not automatically convert a refund request into an exchange. The repository has no product, inventory, shipment, or exchange fields with which to perform that workflow.
